# 🚀 NeonCraft Application

NeonCraft is a lightweight Minecraft utility application designed to enhance user experience with tools like skin viewer, cape checker, and server information scanner.

---

## ✨ Features

- 🎮 Minecraft Skin Finder (via Mojang API)
- 🧥 Cape Viewer Tool
- 🌐 Server Info Checker (IP & Port Scanner)
- ⚡ Lightweight and fast performance
- 🖥️ Simple and clean UI

---

## 📦 Version

Current Version: **v1.0.0 (Initial Release)**

---

## ⚙️ Requirements

- Windows 10 / 11
- Internet connection (for API features)
- x64 system recommended
